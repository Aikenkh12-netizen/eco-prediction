# SuVision

SuVision is a low-cost autonomous IoT monitoring system designed for early prediction of harmful algal blooms and water pollution in lakes and rivers.

## About the Project

The system uses smart sensors to monitor:

- Water temperature
- pH level
- Water turbidity

Collected data is analyzed using artificial intelligence algorithms to predict eutrophication risks 48–72 hours before visible algal blooms appear.

The project includes:
- IoT sensor monitoring
- AI-based prediction
- Streamlit web dashboard
- Environmental data visualization

## Features

- Real-time environmental monitoring
- AI-based prediction system
- Interactive web dashboard
- Low-cost sensor architecture
- Water quality analysis
- Early warning system
