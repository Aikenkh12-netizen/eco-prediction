# SuVision

SuVision is a low-cost autonomous IoT monitoring system designed for early prediction of harmful algal blooms and water pollution in lakes and rivers.

## About the Project

The system uses a network of smart buoys equipped with sensors to monitor:

- Water temperature
- pH level
- Water turbidity

The collected data is transmitted through LoRa communication technology and analyzed using artificial intelligence algorithms to predict eutrophication risks 48–72 hours before visible algal blooms appear.

## Features

- Real-time environmental monitoring
- AI-based prediction system
- LoRa long-range communication
- Interactive web dashboard
- Low-cost sensor architecture
- Autonomous solar-powered buoys
